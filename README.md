# OOPs

Object Oriented Programming

This repository contains simple Java examples (op1.java through op5.java) that demonstrate basic Object-Oriented Programming concepts.

Files

- `op1.java`: Defines a basic `Student` class and creates a `Student` object; sets fields and prints the student's name and age (objects and fields).
- `op2.java`: Adds a `display()` method to `Student` and shows creating multiple instances and calling an instance method (encapsulation / methods).
- `op3.java`: Introduces a constructor `Student(String, int, int)` to initialize objects and demonstrates using `this` inside the class (constructors / initialization).
- `op4.java`: Demonstrates method overloading with several `display` signatures in `Student` (polymorphism via overloading).
- `op5.java`: Demonstrates simple inheritance: `Animal` base class and `Dog` subclass; shows calling inherited and subclass methods (inheritance).

Quick start

- Compile all examples:

```
javac *.java
```

- Run a specific example (replace `opN` with the example number):

```
java op1
java op2
java op3
java op4
java op5
```
